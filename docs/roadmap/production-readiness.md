# Hoja de ruta de producción — EnlaceSeguro

**Actualizada:** 2026-11-04
**Estado:** Diferido para el objetivo universitario vigente. Para la entrega actual manda `docs/roadmap/academic-demo.md` y ADR-0012; los gates G0–G5 solo aplican si después se busca producción.
**Meta:** aplicación iOS/Android, consola web admin y despliegue en nube administrada para mercado inicial México.

Este archivo es el tablero de abordamiento del plan aprobado. No certifica que las fases estén implementadas ni que el sistema esté listo para producción. Cada fase requiere evidencia verificable y aceptación antes de avanzar.

**Control de alcance:** el documento `docs/superpowers/specs/2026-11-04-enlaceseguro-oci-free-poc-design.md` es un spike exploratorio derivado de la solicitud posterior de opciones gratuitas; no es requisito original ni precondición de G0–G5. No debe desplazar entregables centrales ni bloquear otras áreas. No crear plan técnico, código o recursos OCI hasta que el propietario confirme que desea continuar con ese spike.

## Modelo de delegación

El coordinador integra contratos/decisiones y evita modificaciones concurrentes de OpenAPI, design system, manifiestos y documentos canónicos. Cada agente trabaja en un worktree/branch por área, declara rutas propietarias y entrega cambios con pruebas y evidencia. Limitar cada ola a tres agentes de implementación concurrentes más el coordinador.

**Secuencia pendiente — limitada al plan original:**
