# Opciones gratuitas para una POC de EnlaceSeguro

**Evaluación:** 2026-11-04 (hora de Ciudad de México)  
**Estado:** propuesta, no selección de proveedor ni autorización para crear recursos  
**Alcance:** costo inicial y límites de ofertas gratuitas para una POC con datos sintéticos.

## Recomendación ejecutiva

Mantener desarrollo y pruebas integrales en el stack local desechable. Es la única alternativa sin plazo promocional ni facturación cloud que cubre ahora el backend, MongoDB replica set, worker y Sandbox. OCI Always Free es candidato para una POC pequeña en una VM ARM autogestionada, no para replicar la arquitectura administrada objetivo. Google Cloud sigue como candidato temporal financiado con crédito. Ninguno es proveedor seleccionado ni garantía para una POC completa a costo cero; región home, capacidad y controles de red deben validarse antes de decidir.

Ninguna oferta de bienvenida debe considerarse infraestructura gratuita de producción. Ninguna opción gratuita verificada cubre de forma sostenida la topología con Sandbox aislado, egress controlado, Atlas privado, backups y operación. El Sandbox requiere aislamiento frente a metadata/redes privadas; el backend requiere MongoDB con respaldo y conectividad adecuados. Una cuota gratuita o crédito no acredita esos controles ni cubre su operación sostenida.

## Condiciones antes de una POC cloud

1. Precisar objetivo experimental: qué hipótesis de despliegue se probará y qué evidencia puede obtenerse sin exponer el Sandbox.
2. Confirmar elegibilidad y plan de cuenta; mantener el proveedor sin selección hasta una decisión/ADR.
3. Elaborar presupuesto de uso y revisar costos fuera de crédito: red/NAT/proxy, salida a Internet, logs, almacenamiento, Atlas, backups y transferencia.
4. Usar datos estrictamente sintéticos, cuenta/proyecto separados, credenciales mínimas y alertas/límites de gasto disponibles; fijar expiración y destrucción de recursos.
5. Definir prueba de aislamiento SSRF/egress, destino de backups y región de cada dato; terminar con evidencia reproducible y limpieza confirmada.
6. No actualizar plan, habilitar facturación o aprovisionar recursos hasta una autorización explícita con proveedor, alcance y límite de gasto.

## Decisión pendiente

El usuario pidió opciones gratuitas y eligió **priorizar el diseño** de una POC OCI sintética. Esto no selecciona OCI para producción ni autoriza cuentas, facturación, aprovisionamiento o despliegue. La recomendación para pruebas sin costo sigue siendo el stack local; OCI es autogestionada y su VCN/NAT no demuestra el enforcement cloud exigido. Una POC OCI debe declarar si prueba solo ARM64/packaging o también controles host/proxy; ninguna equivale al firewall de egress administrado. Antes de crear recursos hay que confirmar región home/capacidad, costo de red/NAT, presupuesto cero o aprobado y diseño de seguridad; Network Firewall exige cuenta pagada.
