# API

La propuesta describe una API REST para autenticación, validación y coordinación del análisis, persistencia y entrega del resultado. Esas capacidades están **propuestas**, no verificadas en código.

- [`openapi.yaml`](openapi.yaml) es un esqueleto OpenAPI sin rutas; endpoints, payloads, códigos de error y autenticación quedan pendientes de definición.
- No inventar rutas ni contratos a partir de la descripción general.
- Fuente: propuesta académica local; su registro y disponibilidad se describen en [`Context/project/sources.md`](../Context/project/sources.md).
