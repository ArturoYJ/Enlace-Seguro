# EnlaceSeguro

Proyecto académico para explorar una aplicación que analice enlaces sospechosos antes de que el usuario los abra. El diseño propuesto combina una interfaz móvil, una API, almacenamiento de resultados y análisis aislado; las propuestas no deben presentarse como funciones implementadas sin evidencia del código y sus pruebas.
